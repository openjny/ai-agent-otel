# コスト計算

## `analyze.py cost` の出力について

`analyze.py cost` が表示する USD は**トークンベース従量課金を仮定した参考値**です。

### Copilot サブスクリプションの場合

Copilot サブスクリプションを使っている場合、実際の課金は**月額固定 + Premium Request 従量**であり、表示額をそのまま払っているわけではありません。参考値として「API 直接利用だったらこれだけかかる」という目安です。

### 1M コンテキストモデルの注意

claude-opus-4.6-1m のような 1M コンテキストモデルは、会話が長くなるほど入力トークンが膨らみます（全履歴を毎ターン送信するため）。コスト表示が大きく見えますが、これは「長いセッションを続けるより、適切なタイミングで新しいセッションを始めた方がトークン効率が良い」という判断材料として活用してください。

## モデル単価の管理

`scripts/analyze.py` の `MODEL_PRICING` dict でモデル別単価を管理:

```python
MODEL_PRICING: dict[str, tuple[float, float]] = {
    # model_pattern: (input_per_1M, output_per_1M)
    "claude-opus-4.6-1m": (15.0, 75.0),
    "gpt-4o-mini": (0.15, 0.60),
    ...
}
```

新モデル追加時は `MODEL_PRICING` を更新してください。未知のモデルは `$0` と表示され、警告メッセージが出ます。

## キャッシュの扱い

現在の計算ではキャッシュ読み取り (`cache_read.input_tokens`) の割引を考慮していません。実際のコストは表示値より低くなる可能性があります。
